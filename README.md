# InfoTech Gestão - Sistema para Lojas de Informática e Assistência Técnica

Sistema desktop para gestão de assistência técnica e vendas no segmento de informática (computadores, notebooks, monitores e impressoras).

## 🚀 Como Iniciar

1. Duplo clique no atalho **InfoTech Gestão** na Área de Trabalho.
2. Ou execute `INICIAR_INFOTECH.bat` dentro desta pasta.
3. Ou acesse `http://localhost:4567` no seu navegador.

## 📦 Funcionalidades Principais

- **Ordens de Serviço (OS)** com checklist de entrada, controle de status, laudo técnico, peças do estoque e mão de obra.
- **Ponto de Venda (PDV)** com leitor de código de barras, múltiplos pagamentos (Dinheiro, PIX, Débito, Crédito até 12x, Faturado) e cupom de balcão.
- **Orçamentos** com conversão em 1 clique para Ordem de Serviço ou Venda.
- **Estoque & Suprimentos** com alerta automático de estoque mínimo para reposição.
- **Tabela de Mão de Obra** com preços de serviços técnicos e prazos de garantia.
- **Clientes** com histórico completo de aparelhos e atalho para o WhatsApp.
- **Módulo Fiscal** para emissão de NF-e (produtos) e NFS-e (serviços) via API.
- **Backup Diário Automático** em `C:\Users\Power\InfoTech_Backups` com retenção de 30 dias e restauração facilitada.
